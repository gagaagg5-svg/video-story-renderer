VIDEO STORY RENDERER — первая версия

Что делает
Собирает MP4 из статичных кадров и готовой озвучки. Для каждого изображения задается длительность. По желанию можно включить медленный зум и добавить фоновую музыку.

Установка готовой программы на Windows
1. Скачай и распакуй архив установщика из GitHub Actions.
2. Запусти VideoStoryRenderer-Setup.exe и пройди шаги установки.
3. Открой Video Story Renderer из меню «Пуск».
Python и FFmpeg уже входят в готовый установщик.

Запуск исходного кода (только для разработки)
Для исходников нужны Python 3.10+ с Tkinter и FFmpeg/ffprobe в PATH.
Запусти start_windows.bat или команду python video_story_renderer.py.

Как пользоваться
1. Нажми «Добавить кадры» и выбери их в нужной последовательности. Можно менять порядок кнопками ↑/↓.
2. Для каждого кадра выдели строку и нажми «Длительность». Значения указываются в секундах. Стартовое значение — 480 секунд (8 минут).
3. Можно загрузить CSV с двумя колонками: image,duration_seconds. Пути к кадрам в CSV могут быть полными или относительными к папке CSV.
4. Выбери аудиофайл озвучки. Суммарная длительность кадров должна покрывать озвучку.
5. При желании добавь музыку. Ее громкость задается как доля от уровня озвучки.
6. Укажи имя MP4 и нажми «Рендерить видео».

Пример CSV
image,duration_seconds
01_intro.jpg,35
02_room.jpg,480
03_window.jpg,480

Технические настройки
Выход: MP4 (H.264 + AAC), 1920×1080, 30 кадров/сек. Кадры масштабируются и обрезаются под 16:9. Рендер длинного ролика может занять значительное время; временные файлы удаляются после завершения.

Доработки версии 2
- Длительность можно вводить как 480, 08:00 или 00:08:00.
- Плавный зум теперь растянут на всю длительность кадра.
- FFmpeg можно положить рядом с программой или в подпапку bin.
- Настройки фиксируются на момент запуска рендера.
- Существующее видео заменяется только после успешного экспорта.
