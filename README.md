# Video Story Renderer

Windows-программа для сборки длинных видеоисторий из изображений и готовой озвучки.

Возможности: порядок и длительность кадров, CSV с таймингом, медленное приближение на протяжении сцены, фоновый звук, экспорт H.264/AAC в MP4 1920×1080.

## Установщик Windows

Откройте **Actions → Build Windows Installer**, выберите успешную сборку и скачайте **VideoStoryRenderer-Windows-Installer** из раздела **Artifacts**. Распакуйте ZIP и запустите `VideoStoryRenderer-Setup.exe`. Python и FFmpeg включены в установщик. Поддерживается Windows 10/11 x64.

Сборка запускается при изменении `main` или вручную через **Run workflow**. До публикации установщика проверяются функции работы со временем, экспорт видео из упакованной программы и экспорт после установки.

## Исходный код

Для запуска из исходников нужны Python 3.10+ с Tkinter и FFmpeg/ffprobe. Запуск: `python video_story_renderer.py`. На Windows можно использовать `start_windows.bat`.

`README_RU.txt` содержит инструкцию по работе с кадрами и аудио. Длительность задаётся в секундах, ММ:СС или ЧЧ:ММ:СС. Пример: `480`, `08:00`, `00:08:00`.

Это первая версия приложения. Полноценная проверка интерфейса на пользовательском ноутбуке ещё требуется; автоматическая сборка проверяет экспорт и установку.
