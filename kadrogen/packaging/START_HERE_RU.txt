Kadro.Gen — свои изображения и тайминг

1. Распакуйте ВЕСЬ архив в обычную папку, например C:\KadroGen.
2. Запустите KadroGen.exe двойным щелчком. Python устанавливать не нужно.
3. Выберите «Свои изображения», затем MP3 и папку с PNG/JPG/WEBP.
4. При наличии тайминга выберите CSV или XML DaVinci (Final Cut Pro 7 XML).
5. Для короткой проверки всех кадров включите «Пробный экспорт»:
   каждый кадр и вступление будут не длиннее 3 секунд, MP3 начнётся с 00:00.
   Пробный файл _preview.mp4 сохранится отдельно, без субтитров.
6. Нажмите «Начать». Готовое видео появится в папке output.

Не переносите один EXE отдельно от подпапок: ему нужны _internal и ffmpeg.
Ключи API не нужны для сборки ваших изображений и MP3 без субтитров.
Для окна используется Microsoft Edge WebView2 Runtime. На большинстве
Windows 10/11 он уже есть. Если программа попросит WebView2, установите
его с официальной страницы: https://developer.microsoft.com/microsoft-edge/webview2/

Это самостоятельная модифицированная сборка исходников Kadro.Gen 1.7.1.
Автор исходной программы: Гриша Ютубер, https://t.me/Grisha_Youtuber_2003.

При экспорте программа проверяет NVIDIA NVENC и использует видеокарту,
если кодировщик доступен. При невозможности аппаратного кодирования
она использует процессор. С включённым моушн-дизайном переходы:
приближение, сдвиг влево, вправо, вверх и вниз. Кнопка «Проверить
кодирование» покажет причину, если NVENC недоступен. Загруженность GPU
сама по себе не означает работу аппаратного кодировщика.
