Kadro.Gen 1.7.1 — режим «Свои изображения»

Что добавлено
Выберите «Свои изображения» на первом экране. На экране «Доступ» выберите MP3
с озвучкой и папку с вашими изображениями PNG/JPG/WEBP. Программа сортирует
файлы по имени (1, 2, 10, а не 1, 10, 2), распределяет их по таймингу
или поровну по длине озвучки и собирает MP4 1920x1080, 25 к/с.
При желании можно включить переходы и субтитры. В этом режиме не требуются
платные ключи для создания картинок; для субтитров нужен ключ OpenAI API или
fast-gen, поскольку программа распознаёт речь.

Порядок:
1. Назовите кадры 001.jpg, 002.jpg, 003.jpg и так далее; все положите в
   одну отдельную папку. Их исходные файлы программа не изменяет.
2. Создайте озвучку в ElevenLabs и сохраните MP3.
3. На первом экране выберите только «Свои изображения»; режим «Только картинки»
   устанавливается автоматически.
4. На экране «Доступ» выберите MP3 и папку изображений. При желании выберите
   видео MP4/MOV/MKV/WEBM в строке «Видео в начале» и CSV/XML тайминг.
5. Для каждого кадра можно выбрать файл в списке и нажать на нужную точку
   картинки; это будет центр приближения настолько, насколько позволяет
   масштаб кадра. Ползунок «Время приближения» задаёт скорость (6–40 с).
   Включите «Моушн-дизайн», чтобы работали приближение и пять переходов:
   приближение, сдвиги влево, вправо, вверх и вниз. Длинные кадры плавно
   приближаются и отдаляются циклически. Можно добавить лёгкие частицы
   или более заметный эффект старой плёнки с пылью, зерном и царапинами.
   Этот эффект требует дополнительного прохода экспорта.
6. Готовое видео — в output; подготовленные PNG — в jobs/manual_.../images.

Быстрая проба длинного проекта
Если выбран MP3 на 50 минут, десять кадров без тайминга займут по пять минут
каждый. Это длина РОЛИКА, а не точный прогноз времени экспорта. Чтобы
проверить все десять кадров и переходы, отметьте «Пробный экспорт»: программа
возьмёт начало MP3, покажет каждый кадр не более 3 секунд и сохранит
отдельный файл с суффиксом _preview.mp4. Вступление тоже сокращается до
3 секунд. Субтитры в пробе не создаются; частицы можно проверить.
После пробы снимите галочку для полного ролика. «Проверить кодирование»
сообщает, доступен ли NVENC на этом компьютере, и показывает причину
перехода на процессор.

Завершённое или прерванное задание можно запустить повторно с тем же MP3 и
папкой картинок. Если изображения не менялись, подготовленные PNG используются
снова. При изменении файлов программа обновит картинки и пересоберёт клипы.
Тайминг можно менять: при смене длительности клипы будут пересобраны.
Для одного проекта используйте одну папку с
кадрами, не меняйте её во время сборки.

Форматы тайминга:
- CSV в UTF-8: столбцы filename,duration_seconds; например:
  filename,duration_seconds
  intro.mp4,3.0
  001.jpg,2.5
  002.png,4.0
  003.webp,3.5
  Если выбрано вступительное видео, укажите его первой строкой: тайминг
  считается с 00:00. Указанная длительность видео управляет обрезкой или
  продлением последнего кадра вступления. Старые CSV только с картинками
  тоже принимаются: их сумма должна равняться остатку MP3 после вступления.
  Без filename допускается один столбец duration_seconds в порядке видео
  (если есть) и отсортированных по имени изображений.
- DaVinci Resolve: экспортируйте таймлайн как Final Cut Pro 7 XML (FCP 7 XML).
  Нужна одна непрерывная видеодорожка, начиная с 00:00: вступительное видео
  и затем каждое изображение ровно один раз. Старый XML только с картинками
  (с 00:00 или с конца вступления) также подходит. Программа сопоставит
  клипы с файлами по имени и возьмёт start/end и FPS таймлайна.

Если выбрано вступительное видео, оно идёт от начала MP3 и его исходный
звук отключается. Без тайминга видео идёт в своей исходной длительности;
кадры делят оставшееся время. Сумма видео и кадров должна совпадать с MP3
с погрешностью до 0,15 с.
Если в DaVinci голос был замедлен или ускорен, экспортируйте именно такую
озвучку в MP3. При расхождении программа покажет обе длительности и отменит
сборку. Видео выводится в 25 к/с, поэтому границы из проекта с другой
частотой кадров могут округлиться на один кадр. Кнопка «Убрать» возвращает
равномерное распределение.

Запуск на Windows
Распакуйте архив целиком и запустите KadroGen.exe в папке KadroGen.
Python устанавливать не требуется. Исходники доступны в ветке
kadrogen-windows репозитория video-story-renderer.

В исходной версии программа обновлялась автоматически. Для этой собственной
сборки автоматическое обновление выключено, чтобы не стереть изменения.
