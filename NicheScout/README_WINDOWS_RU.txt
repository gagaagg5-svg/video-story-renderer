NICHE SCOUT 0.1.1 — WINDOWS 10/11, 64 BIT

УСТАНОВКА
Запустите NicheScout-Setup.exe и следуйте шагам мастера.
После установки откройте Niche Scout через ярлык на рабочем столе
или из меню «Пуск». Устанавливать Python не нужно.

БЕЗ УСТАНОВКИ
Альтернатива — открыть NicheScout.exe из скачанной папки.
Этот файл уже содержит необходимые компоненты Python.

ПЕРВЫЙ ЗАПУСК
1. Нажмите «Демо»: интерфейс покажет три вымышленных примера бесплатно.
2. Для реального поиска зайдите в https://app.vidiq.com
   Account Settings → MCP → создайте API key.
3. Вставьте ключ в поле программы и нажмите «Проверить подключение · 0».
   Ключ хранится только до закрытия программы. В чат его присылать не нужно.
4. Выберите язык, тему и пороги. По умолчанию: 100 000 просмотров
   за 21 день, до 50 000 подписчиков, длинные видео от 20 минут.
5. Нажмите «Найти кандидатов». Ожидаемая стоимость будет показана
   до платного запроса. Поиск расходует кредиты vidIQ.
6. Выберите видео → «Проверить выбранный канал · 10».

Установленное расширение vidIQ не передаёт программе доступ автоматически.
Для самостоятельного подключения требуется API key.

Для румынского используется поиск фраз: язык результатов нужно проверить.
Чужие фактические доходы и страны зрителей программе недоступны.
RPM на вкладке прибыли — ваши допущения, а не данные о странах.
Количество конкурентов относится только к найденной выборке.

Результаты автоматически сохраняются в %LOCALAPPDATA%\NicheScout.
Сохранённый JSON можно открыть через «Импорт JSON».
Подробности метода и ограничения — вкладка «Метод и ограничения»
и файл README_RU.md.

Проверка сборки включает тесты кода, запуск окна программы,
работу демо и калькулятора, тихую установку и запуск установленной копии.
Проверки не отправляют платные запросы vidIQ.
