# Niche Scout 0.1.1

Программа для поиска свежих успешных длинных видео у небольших каналов через vidIQ. Локальное настольное приложение на русском. В сборке Windows доступны NicheScout-Setup.exe (установщик) и NicheScout.exe (запуск без установки). Для этих файлов Python на ноутбуке не требуется. Инструкции ниже про Python относятся к запуску исходного кода разработчиком. Дополнительных Python-пакетов для исходного кода нет; требуется Python 3.10 или новее с Tkinter.

## Как запустить на Windows

1. Распакуйте весь архив в обычную папку.
2. Если Python ещё не установлен: установите его с https://www.python.org/downloads/windows/ . Оставьте включённым компонент Tcl/Tk and IDLE. Для обычной установки подходят Python 3.12–3.14.
3. Дважды нажмите `START_WINDOWS.bat`.
4. Нажмите **Демо**, чтобы посмотреть интерфейс без ключа. Демонстрационные видео, каналы и показатели вымышлены; они не являются рекомендациями ниш.
5. Для реального поиска откройте https://app.vidiq.com → Account Settings → MCP. Создайте API key и вставьте его в поле программы. Не отправляйте ключ в чат. Ключ остаётся в памяти программы и отправляется только официальному серверу vidIQ.
6. Нажмите **Проверить подключение · 0**. Это проверяет ключ и баланс без платного исследования. Подключение vidIQ внутри ChatGPT не переносится автоматически в скачанную программу: нужен отдельный ключ.
7. Выберите язык и тему, проверьте фильтры. **Найти кандидатов** покажет ожидаемый расход перед запросами. Одна строка темы = один запрос. Пустая тема ищет все темы, кроме румынского, для которого необходима фраза.
8. Выберите настоящее видео и нажмите **Проверить выбранный канал · 10**. Отчёт появится на второй вкладке. Это отдельный запуск с отдельным лимитом, а не часть бюджета уже выполненного поиска.

Если `py` не найден, запуск попробует `python`. Если окно сразу закрывается, откройте командную строку в папке программы и выполните `py -3 scout.py`. В Linux может потребоваться пакет `python3-tk`. Mac: Python с рабочим Tkinter, запуск `python3 scout.py`.

## Что умеет версия 0.1

- Польский, испанский, английский: поиск трендов (абсолютная скорость) и outliers (успех относительно обычных результатов канала).
- Румынский: обычный поиск YouTube через vidIQ по румынским фразам. Специальный фильтр языка outliers/trending в доступной схеме ro не поддерживает. Поэтому язык результатов НЕ считается подтверждённым; регион RO также не подтверждает язык или страну зрителей.
- Фильтры: возраст видео, просмотры, подписчики, длительность. Длительность от 20 минут; румынский поиск сервиса использует категорию long (>20 минут). Для более коротких форматов потребуется отдельный режим.
- Локальная повторная проверка даты, просмотров, подписчиков и длительности: серверные фильтры не считаются доказательством их соблюдения.
- Текущий VPH и breakout только когда они предоставлены vidIQ. Программа не выдаёт среднюю скорость за всю жизнь видео за текущую.
- Проверка даты регистрации канала, истории роста и последних длинных видео. Недавнее начало проекта определяют отдельно: дата регистрации и начало возвращённой выборки этого не доказывают.
- Медиана просмотров и число успешных свежих публикаций. Это статистика ограниченной выборки, не оценка всего рынка.
- Дедупликация видео, сохранение дат наблюдений, экспорт CSV, импорт JSON. Нажатие нового поиска сохраняет прошлую подборку и начинает новую.
- Сценарии прибыли с ручными значениями RPM, просмотров и затрат. Валюта USD, до налогов; примерные RPM 1/3/5 произвольны и не относятся к конкретным странам.
- Сохранение успешных и частичных результатов после выполнения запроса. На Windows: `%LOCALAPPDATA%\NicheScout`. Файлы `run_*.json` старше 30 дней удаляются при следующем сохранении. Экспортированные вами копии автоматически не удаляются. Результаты можно загрузить через **Импорт JSON**.

## Кредиты

По документации на 17.10.2026: проверка баланса бесплатна; поиск — 5 кредитов за запрос; проверка канала использует два запроса, ожидаемо 10. Это плановая стоимость, не обещание неизменного тарифа. Проверяйте действующие цены vidIQ.

Перед каждым исследованием программа показывает ожидаемый расход и требует нажатия кнопки запуска. При неизвестном или недостаточном балансе исследование останавливается. Платные запросы не повторяются автоматически после сетевой ошибки. Даже если ответ потерян, списание возможно: программа отдельно показывает неизвестные списания. Подтверждённый расход учитывается только по `_credits.used`, когда поставщик возвращает это поле. Лимит кредитов относится к одному действию пользователя, не ко всему дню.

Список разрешённых действий ограничен чтением баланса, поиском и публичной статистикой. Загрузка, публикация, изменение каналов, генерация медиа и изменение списка конкурентов в программу не включены.

## Как применять присланный метод

Исходный пресет: видео опубликовано за 21 день, 100 000+ просмотров, до 50 000 подписчиков. Число подписчиков — выбранный стартовый порог, не правило автора метода. Отбор молодых каналов выполняется на этапе проверки: регистрация недавно — только один сигнал.

1. Найдите свежие успешные публикации на нужном языке.
2. Проверьте минимум несколько независимых каналов. Смотрите следующие публикации, а не только рекордное видео.
3. Исследуйте конкурентов по нескольким синонимам и уточнениям темы. Один ответ сервиса ограничен 50 результатами и его покрытием. Программа не листает весь YouTube.
4. Вручную изучите содержание, источники, качество языка и сложность производства. Похожие заголовки не доказывают одинаковую нишу или формат.
5. Посчитайте сценарии экономики, включая перевод, редактуру носителем языка, голос, изображения и монтаж.
6. Проверьте идею оригинальными публикациями. Утверждения «RPM ×10», «монетизация за четыре дня» и «видео за 20 минут» остаются неподтверждёнными заявлениями из источника метода. Продолжительность ролика и язык сами по себе не определяют доход.

«Разведчики» используют персональную рекомендательную ленту. Программа её не читает и не имитирует: рекомендационный алгоритм и индекс поиска vidIQ — разные источники. Покупка каналов, просмотр видео до конца и лайки для приложения не нужны. Ссылки из ручной разведки можно отдельно изучать через ChatGPT и импортировать ответы JSON.

## Импорт

Поддерживаются ответы vidIQ `trending_videos`, `outliers`, `youtube_search`, их MCP-обёртки `structuredContent`/`content`, список видео, а также сохранённые запуски Niche Scout. Для обычного ответа допустимы поля верхнего уровня `language` и `observed_at`; без них язык обозначается unknown, дата наблюдения — дата импорта. В сохранённых запусках сведения об источнике и датах остаются.

Отсутствующие дата, просмотры, подписчики или длительность не заменяются нулём и не проходят строгий фильтр. История результатов не восстанавливает показатели, которых поставщик не возвращал. Таблица показывает дату публикации, экспорт также содержит дату наблюдения: старый импорт не является свежей статистикой.

## Условия и проверка

Данные vidIQ остаются предметом условий vidIQ и YouTube. API key не предоставляет автоматически любые права на вычисление, хранение и перепродажу данных. Для собственной прямой интеграции с YouTube API требуется проверить условия аналитических метрик и при необходимости согласовать использование. В версии нет прямого YouTube API и обхода лимитов аккаунтами/прокси.

Проверка в среде разработки: компиляция Python, автоматические тесты нормализации ответов, фильтрации, расчётов, плана запросов, JSON/SSE и бюджета. Реальное соединение скачанного клиента с API key пользователя и поведение окна под Windows требуют проверки на вашем компьютере. Ключ пользователя в среде разработки не использовался; платных исследовательских запросов при подготовке не выполнялось.

Официальные источники:

- https://support.vidiq.com/en/articles/15082430-vidiq-mcp
- https://vidiq.com/gemini-cli/ (пример заголовка Authorization: Bearer для API key)
- https://developers.google.com/youtube/terms/developer-policies
- https://developers.google.com/youtube/terms/derived-metrics-policy

## Разработчику

Весь код — `scout.py`. Транспорт: официальный Streamable HTTP MCP на https://mcp.vidiq.com/mcp , инициализация, динамическое чтение имён/схем инструментов, JSON и SSE. Автоматические перенаправления с ключом отключены. Никаких ключей, аккаунтов и личных данных в архиве нет. Для тестов: `python -m unittest discover -s tests -v`.
